# 08 - Performance

Scope: what the project's code costs in time and memory, measured and explained: seconds per AI turn (x64 server
and 32-bit DLL, headless and in the real EXE), crossings of the EXE<->DLL boundary through the proxy and the time
per crossing, frame time through the proxy against the 32-bit DLL, load and save time, memory and per-turn growth,
and later the server's render time and the composite latency. Kept by the standing performance standards team
(tracker 7000, decision D40); every number carries its date, build, configuration, method and a trust grade
(A-D, defined at the top of `inventory.md`). Standards for the other teams are in `docs/briefs/PERFORMANCE.md`;
benchmark tools under `perf/`; their exact commands (quiet lock, turn benchmark, testbed series, memory
sampler, metrics ledger, diskwatch) are in [the runbook](../06-tooling-and-workflows/runbook.md) section 5 (D233).
