# 03 - DLL / engine boundary

Scope: the interface between the Civ V EXE (`CivilizationV_DX11.exe`, 32-bit, closed) and the Vox Populi DLL
(`CvGameCore_Expansion2.dll`): its shape (ICv* interfaces, Lua libraries, gDLL calls), the traffic measured live on
2026-11-09, what that traffic would cost over cross-process IPC between a 32-bit proxy DLL and a 64-bit server, what
is known about building the DLL for x64, the `civ5-headless` host the server is modelled on, and the effort
estimates as they stood on each date. Everything here is copied or synthesised from the files under
`research/sources/`; nothing was re-measured. Where sources disagree, the files say so.
